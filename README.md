## Pre-install

- To use husky run pnpm prepare in root
- Then give rules chmod +x .husky/pre-commit

### Requirements

- node 24.14.0
- pnpm as package manager

## Development

- Add variables to bash K_ROOM_MAIL_PASS, VITE_FIREBASE_API_KEY
- Run sh dev.sh

## Deploy

- Just merge to main branch
